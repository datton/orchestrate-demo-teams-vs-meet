# teams-vs-meet.demo.orchestrate.ca

A fair, text-only comparison of Microsoft Teams and Google Meet.
Built live by the Orchestrate Solutions agent team in an Orchestrate demonstration. Static site: HTML, CSS and JavaScript, no build step.

**Text-only:** no SVG, images, icons, canvas or icon fonts anywhere. Visual interest comes from typography and CSS only.

## Pages
- `index.html`: Home
- `pages/microsoft-teams.html`: Microsoft Teams
- `pages/google-meet.html`: Google Meet
- `pages/side-by-side.html`: Side by side comparison
- `pages/which-should-you-choose.html`: Which should you choose
- `pages/about.html`: About this site

## Lanes
- Designer: `css/tokens.css` (typography, colour; no assets)
- UI/UX: `css/layout.css`, `js/nav.js`, header/nav/footer
- Full-Stack: page content, `js/app.js`
- Lead Developer: scaffold, README, `css/site.css`
